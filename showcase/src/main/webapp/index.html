Source and usage

Move and reorder cards

Use a card’s handle to move it between the first two columns, or change its position in a column. The third column rejects drops and returns the card to its original position. The text fields remain editable.

What this example uses

The board uses the original PickupDragController and VerticalPanelDropController APIs. Java callbacks report completed or cancelled moves. A separate handle keeps form controls usable while a card is draggable.

Tea DnD maintains Fred Sauer’s GWT-DnD for modern GWT and TeaVM. This alpha retains mouse and touch handling; keyboard dragging is not implemented.
